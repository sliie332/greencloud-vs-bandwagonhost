## 到中国大陆的访问质量：两者真正的分水岭

绿云的低价套餐走标准国际 BGP 路由，到中国大陆没有直连优化，晚高峰拥堵丢包是这类线路的常态。绿云机房里对国内体验相对较好的是香港 CN2 和东京机房（有评测称东京到电信/联通延迟 50–80ms），但这些都是它的高成本精品线路，价格和「年付十几美元」的 Budget 系列不是一回事。

搬瓦工 CN2 GIA 方案的三网回程都走电信 CN2 GIA 优质路由，晚高峰表现稳定，这也是它在中文圈口碑积累多年的核心原因。前面提到的 GIA-E 系列和大阪线都属这一类。

所以判断标准可以很简单：国内用户白天晚上都要流畅访问 → 线路优先，看搬瓦工；访客在海外、或者你自己只是 SSH 上去管理 → 线路不敏感，价格和配置优先，看绿云。中间态的需求（比如主要给国内访问但预算只有绿云的水平），绿云的香港/东京精品线路可以看看，但要做好价格接近搬瓦工 GIA 的心理准备。

## 绿云的三条硬限制，下单前必须知道

**第一条，退款。** 绿云所有特价、大促、促销套餐一律不支持退款，这是写在购买页上的，每一档 Budget KVM Sale 机型都标着「No refund/Money back on this plan」。普通原价月付套餐也只对首次客户开放 7 天内申请，且比特币支付不退款。有资深玩家给出的稳妥做法是：先小额买一个月付原价机型（Ryzen KVM 月付 $6 就是干这个用的），用和自己真实访客相近的网络测延迟和丢包，确认满意再入手特价年付机锁价。说得更直白些：特价机付出去的钱当预付款看待，别指望反悔。这也是为什么建议 👉 [用月付机型先测线路，再决定是否上特价年付](https://greencloudvps.com/billing/aff.php?aff=6679)。

**第二条，CPU 占用限制。** 绿云对 CPU 共享限制较严：连续 30 分钟以上占满 100% vCPU（长时间视频压制、大型项目编译、高频量化这类负载），会被自动限速甚至强行关机。它适合网站、Docker 服务、备份这类间歇性负载，想当持续满载的计算节点就别指望了。

**第三条，管理方式。** 绿云是不管型（Unmanaged）服务，工单制、纯英文客服，只负责底层网络和母机稳定，系统内软件问题不协助排查。官网标称平均工单响应 9 分钟，Trustpilot 上有 120 条评价、3.7 分，响应速度不算短板，但你得自己会处理服务器上的事。另外绿云低价套餐内存普遍只有 1–2GB，部署 WordPress 或轻量 Docker 后建议手动创建 1GB Swap 并把 swappiness 设为 10，避免数据库进程因内存不足被杀。

## 常见问题

**绿云支持支付宝吗？**
支持。绿云接受支付宝、微信、PayPal 和比特币等多种付款方式，对国内用户付款友好；但注意比特币支付不退款。

**绿云的 Windows VPS 怎么么样？**
绿云提供专门的 Windows RDP 实例，Hyper-V 虚拟化，10Gbps 端口，月付 $10 起，黑五期间 Budget Windows VPS 也参与过 5 折活动。轻量桌面办公用途可以考虑，但预算同样要考虑它不退款的政策。

**搬瓦工流量用完了怎么办？**
不会产生超量费用。搬瓦工流量按购买日起算月周期（3 号买的，下月 3 号重置），用完后 VPS 自动暂停，等下个周期重置即恢复；也可以随时在后台升级套餐立即恢复使用。它不能单独加钱买流量，暂停期间也无法操作机器。

**两家谁更稳定？**
绿云官网承诺 99.99% 网络和电力在线率并公开状态页，Trustpilot 3.7 分；搬瓦工运营年限长、CN2 线路口碑积累深。涉及重要业务时，两家都建议做好异地备份，别把单一 VPS 当唯一存储。
